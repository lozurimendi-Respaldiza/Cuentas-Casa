NexoFinanzas
App centralizada para gestionar tus cuentas familiares. Los datos se sincronizan en tiempo real entre todos tus dispositivos.

⚙️ Paso 1 — Configura Google Sheets

  1. Abre sheets.google.com y crea una hoja nueva
  2. Nómbrala NexoFinanzas
  3. Abre Extensiones → Apps Script
  4. Borra el contenido y pega el código de abajo
  5. Guarda, luego pulsa Implementar → Nueva implementación → Aplicación web
  6. Acceso: Cualquier usuario → Implementar → Copia la URL

🔗 Paso 2 — Pega la URL del script

Copia la URL que obtuviste al implementar la aplicación web en Apps Script.

⚠ Sin conexión — los cambios se guardarán localmente y se sincronizarán al reconectar
